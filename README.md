## 🌌 Overview

**NeuroMesh** solves one of the most significant bottlenecks in Artificial General Intelligence (AGI) research: **How do isolated, heterogeneous AI agents share cognitive memory securely?**

Traditional AI models are locked in silos. NeuroMesh provides a cryptographic, privacy-preserving semantic synchronization layer that allows AI swarms to project different mathematical vector spaces (e.g., 384d from `MiniLM` and 768d from `DistilRoBERTa`) into a shared, trustless "cognitive brain."

## 🚀 Key Features

- 🧠 **Cross-Model Semantic Synchronization**: Implements random projection matrices to align vectors from mathematically incompatible models on a decentralized ledger.
- 🔐 **Privacy-Preserving Ledgers**: All context data is encrypted client-side using `AES-256-GCM` before being uploaded to IPFS. Only authorized identities hold the decryption keys.
- ⚖️ **Bayesian Trust & Reputation**: Agents mathematically endorse or report others based on memory quality. The network organically quarantines "hallucinating" nodes via an on-chain global trust score.
- ⚡ **Pure Data Simulation**: The network node simulation uses 100% exact, live ML embeddings (`@xenova/transformers`) mapped onto the Sepolia Testnet. **Zero dummy data.**

1. **Information Ingestion**: An AI node ingests text context.
2. **Feature Extraction**: Generates exact vectors (`384d` or `768d`) via local HuggingFace ONNX runtime.
3. **Encryption**: AES-256-GCM symmetric encryption secures the payload.
4. **Decentralized Pinning**: Context and metadata are pinned to IPFS (via Pinata).
5. **Blockchain Proof**: CID and vector dimensionalities are committed to the `MemoryLedger` on Sepolia.

## ⚙️ Quick Start Simulation

Want to run the complete node simulation on your machine?

```bash
# 1. Install dependencies
npm install

# 2. Configure Environment (Create .env)
# PINATA_JWT=...
# SEPOLIA_RPC_URL=...
# PRIVATE_KEY=...

# 3. Run the pure data simulation
node scripts/simulate.js
```

This will trigger the full AI feature-extraction pipeline locally and commit exact data proofs to the blockchain.
